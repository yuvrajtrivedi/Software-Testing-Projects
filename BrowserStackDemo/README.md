# Manual & Cross-Browser Testing Project: BStackDemo

## 📌 Project Overview
This project contains a comprehensive manual testing analysis of the **BStackDemo** e-commerce web application (`https://bstackdemo.com/`). The goal was to perform end-to-end functional, negative, boundary value, and cross-browser testing on real mobile and desktop environments to ensure seamless user experience and system stability.

## 🛠️ Testing Scope & Techniques Applied
- **Functional Testing:** User Authentication, Product Filtering, Cart Operations, Checkout Workflow.
- **Negative & Boundary Value Testing:** Invalid Form Submissions, Extreme Quantity Modifications, Unauthenticated Checkout Attempts.
- **Cross-Browser & Cross-Device Testing:** Executed using **BrowserStack Live** on real iOS and Android devices.
- **Defect Tracking:** Documented edge-case bugs and UI/UX issues with reproducible steps.

## 🧰 Tools Used
- **Testing Application:** BStackDemo E-Commerce
- **Cross-Browser Platform:** BrowserStack Live (iPhone 15 Safari, Samsung Galaxy S23 Chrome, macOS Safari)
- **Developer Tools:** Chrome DevTools (Network & Console inspection)
- **Documentation:** GitHub Markdown, CSV Logs
