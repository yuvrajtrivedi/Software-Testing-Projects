1️⃣ Role-Based Access Control (RBAC) & Security
"I did not limit the testing to basic authentication; instead, I focused heavily on Role-Based Access Control (RBAC) between Admin and ESS (Employee Self Service) user roles. Additionally, I performed security checks such as direct URL access manipulation to ensure unauthorized users cannot bypass authentication."

2️⃣ PIM & Employee Onboarding Lifecycle
"In the PIM module, I tested the end-to-end employee onboarding flow. I applied Boundary Value Analysis (BVA) and file format validation rules. During this phase, I identified a High-Severity Defect where the system accepted non-image formats like .pdf or .docx for profile photos without triggering client- or server-side validation errors."

3️⃣ Leave Management Workflow
"I validated multi-step business workflows—including submitting leave requests as an employee, verifying accurate leave balance deductions, validating date-range overlaps, and executing manager workflows for leave approvals and rejections."

4️⃣ Defect Tracking & Quality Sign-Off
"Finally, I mapped all executed test cases against the Requirements Traceability Matrix (RTM), documented defect reports with full reproduction steps, and performed risk evaluation before issuing a formal QA Sign-off for staging deployment."
